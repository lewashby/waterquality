# Water Quality Management

Water quality measures and predictions

## Installation

Install poetry following the official [documentation](https://python-poetry.org/docs/).

```bash
git clone https://github.com/lewashby/waterquality.git
cd waterquality
poetry install
```

## Usage

```bash
poetry run waterquality
```

You will get the commands help and how to use.

### Default data sources

Sensors data: waterquality/data/Fitterizzi_output.csv \
Weather data: waterquality/data/Meteo Agosto 22 - Luglio 23.xlsx
